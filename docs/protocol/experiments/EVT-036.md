# EVT-036 — Quantum Spatial mode and geometry

Date: 2026-09-16
Transport observed: Windows 11 VM, USBPcap, dongle `0ecb:2069`
Initial condition: spatial audio enabled; DTS selected
Action sequence:

1. select Quantum Spatial;
2. change room size from large to medium;
3. change room size from medium to small;
4. change head diameter from 25 cm to 20 cm;
5. change head diameter from 20 cm to 15 cm;
6. stop capture without returning to DTS.

## Result

None of the five UI transitions produced a USB transfer to the JBL device.
There was no HID Feature Report, HID interrupt notification, or USB Audio
class-control request. Only the ongoing audio stream and initial descriptor
enumeration were present.

## Conclusion

DTS/Quantum Spatial selection, virtual room size, and head-diameter
personalization are all QuantumENGINE host-side DSP parameters. A Linux
implementation requires a spatial-processing pipeline but no vendor USB
command.

The capture filename mentions a DTS return, but the experiment ended after the
15 cm selection. The documented action sequence, not the filename, is
authoritative.
