# EVT-024 — Logo segment 0 color

Date: 2026-09-16
Transport observed: Windows 11 VM, USBPcap, dongle `0ecb:2069`
Initial condition: synchronization disabled; Logo segment 0 color `#33ffcc`
Action: apply `#112233`, wait, then restore `#33ffcc`

## Observed

Applying the test color produced a complete lighting-profile write containing:

```text
4d 00 00 11 22 33 02 00
```

Restoring the original color produced:

```text
4d 00 00 33 ff cc 02 00
```

QuantumENGINE sent each complete profile more than once around the explicit
apply/save actions. Both repetitions contained the expected color. Other
segments and the second zone retained their previous values.

## Confirmed Report `0x4d` fields

```text
4d ZZ SS RR GG BB ?? PP
```

| Field | Meaning | Evidence |
|---|---|---|
| `ZZ` | zone index | `00` selected Logo; startup also carries zone `01` |
| `SS` | segment index | selected first segment is `00`; remaining entries use `01`–`04` |
| `RR GG BB` | literal RGB color | controlled `112233` and restored `33ffcc` |
| `??` | effect identifier | `02` for the displayed Logo “Onda” pattern; independently confirmed by EVT-025 |
| `PP` | likely segment position | values `00,02,04,06,08` correlate with the five ordered segments |

Zone `01` used value `05` in the unknown/effect byte during this capture,
showing that the byte is zone-pattern dependent. Its exact semantics remain a
hypothesis until that zone's effect is changed independently. EVT-025 later
confirmed `01` as Solid and `02` as Wave for Logo segment 0.
