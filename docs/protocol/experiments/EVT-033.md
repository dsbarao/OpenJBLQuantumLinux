# EVT-033 — QuantumENGINE ambient sound control

Date: 2026-09-16
Transport observed: Windows 11 VM, USBPcap, dongle `0ecb:2069`
Initial condition: ambient control off; ANC selected in the UI
Action: enable ANC, select TalkThru, then disable ambient control

## Observed

```text
 2.849 s  SET_FEATURE 46 01
 2.920 s  INTERRUPT IN 02 01

10.013 s  SET_FEATURE 46 02
10.510 s  INTERRUPT IN 02 02

17.442 s  SET_FEATURE 46 00
17.905 s  INTERRUPT IN 02 00
```

## Conclusion

Feature Report `0x46` commands ambient mode and Input Report `0x02` confirms
the resulting state. Both use `00` off, `01` ANC, and `02` TalkThru. This is a
complete command/confirmation mapping, but Linux write support remains gated
behind explicit safety design and is not implemented by this experiment.
