# EVT-016 — Bluetooth pairing mode

Date: 2026-09-16
Transport: 2.4 GHz dongle hidraw, opened read-only

## Actions and observations

Long press until audible notification and Bluetooth LED illumination:

```text
03 02
08 5a
```

Short press while pairing mode was active; LED turned off:

```text
03 00
```

## Confirmed mapping

| Report | Payload | Meaning |
|---|---:|---|
| `0x03` | `0x00` | Bluetooth disconnected / pairing inactive |
| `0x03` | `0x02` | Bluetooth pairing active |

EVT-017 later confirmed payload `0x01` as Bluetooth connected.

Report `0x08` with unchanged payload `0x5a` was resent when pairing mode began,
consistent with a battery/status refresh.
