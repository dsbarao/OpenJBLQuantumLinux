# EVT-020 — analog cable with noise control off

Date: 2026-09-16
Transport observed: 2.4 GHz dongle hidraw, read-only
Initial condition: noise control already off
Action: connect and disconnect the 3.5 mm audio cable

## Result

No HID Input Report was observed.

## Conclusion

The analog jack does not emit a dedicated spontaneous report on the dongle HID
interface. The `02 00`/`02 01` sequence in EVT-019 represented the side effect
of disabling active noise control while the cable was connected and restoring
the previous ANC mode afterward, not a jack-presence field.

Report `0x07` was still unidentified by this passive experiment. It was later
identified as lighting state by the controlled QuantumENGINE capture EVT-022.
