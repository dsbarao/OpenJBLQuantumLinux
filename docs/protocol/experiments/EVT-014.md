# EVT-014 — initial ANC/off observations

Date: 2026-09-16
Transport: hidraw, opened read-only
Action: ANC toggled off/on repeatedly

## Observed sequence

```text
02 00  ANC off
02 01  ANC on
02 00  ANC off
02 01  ANC on
02 00  ANC off
02 01  ANC on
```

## Confirmed mapping

| Report | Payload | Meaning |
|---|---:|---|
| `0x02` | `0x00` | ANC off |
| `0x02` | `0x01` | ANC on |

Six consecutive transitions followed the same binary pattern. The `02 01`
present in earlier startup snapshots therefore records ANC enabled at startup.

EVT-018 later identified a third value, `02 02` for TalkThru. Report `0x02`
therefore represents the complete noise-control mode rather than a binary ANC
toggle.
