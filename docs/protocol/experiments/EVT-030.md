Date: 2026-09-16
Transport observed: Windows 11 VM, USBPcap, dongle `0ecb:2069`
Initial condition: noise reduction disabled
Action: apply low, medium, high, then restore disabled

## Result

No USB transfer to the JBL device occurred during any transition. The capture
contains the existing audio stream and initial descriptor enumeration, but no
HID Feature Report, HID interrupt notification, or USB Audio class-control
request caused by the four UI changes.

The user also reported no immediately perceptible audible change. Audibility is
not required for the transport conclusion; a controlled recording would be
needed to characterize the host-side DSP itself.

## Conclusion

QuantumENGINE implements microphone noise reduction on the Windows host, like
DRC, rather than as a dongle/headset setting. A Linux equivalent belongs in a
PipeWire/DSP layer and does not require a vendor USB write.
