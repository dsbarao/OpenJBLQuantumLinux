## Descriptor-backed interpretation

Report `0x2f` belongs to the Telephony usage page. Its second bit is declared
with Usage `0x2f`, Phone Mute, so payload `0x02` asserts that usage and `0x00`
clears it. EVT-005 therefore contains a Phone Mute key-like assertion followed
by release. The report may represent a momentary host control rather than the
persistent microphone state.

Report `0x06` belongs to the vendor-defined usage page `0xff13`; its meaning is
not specified by the HID standard. The short `01` to `00` transition on boom-up
and the different boom-down sequence require repetition before interpretation.
