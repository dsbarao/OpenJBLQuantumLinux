# EVT-025 — Logo segment 0 effect

Date: 2026-09-16
Transport observed: Windows 11 VM, USBPcap, dongle `0ecb:2069`
Initial condition: Logo segment 0, color `#0029ff`, Wave effect
Action: apply Solid, wait, then restore Wave

## Observed

Applying Solid produced:

```text
4d 00 00 00 29 ff 01 00
```

Restoring Wave produced:

```text
4d 00 00 00 29 ff 02 00
```

All fields except byte 6 remained identical. The application sent the complete
two-zone profile after each change and the dongle returned `07 01`, confirming
that lighting remained enabled.

## Conclusion

The penultimate byte in Feature Report `0x4d` is the segment effect identifier:

- `0x01`: Solid;
- `0x02`: Wave.

Breathing and Glitch remain unmapped.
