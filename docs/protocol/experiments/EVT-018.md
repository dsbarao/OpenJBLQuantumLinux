# EVT-018 — ANC/TalkThru mode cycle

Date: 2026-09-16
Transport: hidraw, opened read-only
Action: cycle the headset noise-control modes twice

## Observed sequence

```text
02 02  TalkThru
02 01  ANC on
02 00  noise control off
02 02  TalkThru
02 01  ANC on
02 00  noise control off
```

## Confirmed Report `0x02` mapping

| Payload | Mode |
|---:|---|
| `0x00` | Noise control off |
| `0x01` | ANC on |
| `0x02` | TalkThru |

Two complete repetitions followed the same three-state cycle. Earlier
documentation that described Report `0x02` as binary ANC state is superseded
by this mapping.
