# EVT-017 — Bluetooth connection state

Date: 2026-09-16
Transport observed: 2.4 GHz dongle hidraw, read-only
Action: connect a previously paired Bluetooth device, then disconnect it

## Observed sequence

```text
connect:     03 01
disconnect:  03 00
```

## Complete Report `0x03` mapping

| Payload | Bluetooth state |
|---:|---|
| `0x00` | Disconnected / pairing inactive |
| `0x01` | Connected |
| `0x02` | Pairing mode active |

The three states are now confirmed by controlled actions and physical/device
feedback across EVT-016 and EVT-017.
