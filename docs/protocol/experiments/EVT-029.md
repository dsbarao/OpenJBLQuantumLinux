# EVT-029 — microphone sidetone levels

Date: 2026-09-16
Transport observed: Windows 11 VM, USBPcap, dongle `0ecb:2069`
Initial condition: sidetone disabled
Action: apply low, medium, high, then restore disabled

## Observed

```text
Low:    5d 01
Medium: 5d 02
High:   5d 03
Off:    5d 00
```

Each change was sent as HID SET_FEATURE Report `0x5d` on interface 5. The
descriptor declares this as a one-byte Feature Report payload.

One later `02 00` Input Report indicated noise control off and is unrelated to
the sidetone transitions.

## Conclusion

Report `0x5d` controls hardware sidetone with ordinal values `00` through `03`.
The Portuguese UI labels (`Graves`, `Médios`, `Agudos`) describe low, medium,
and high intensity rather than audio frequency bands.
