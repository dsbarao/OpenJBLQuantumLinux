## Conclusions

- Confirmed: Report `0x09` payload `0x00` represents the off/disconnected
  state observed when the headset is switched off.
- Confirmed: Report `0x09` payload `0x01` represents the on/connected state
  observed when the headset is switched on.
- Confirmed: switching on triggers a repeatable state snapshot containing
  reports `0x02`, `0x06`, `0x10`, `0x07`, `0x03`, and `0x08`.
- Not yet distinguished: whether `0x09` specifically means headset power,
  wireless link presence, or both as seen from the dongle.
- Hypothesis: Report `0x08` payload `0x5a` may be battery percentage 90. A
  capture at a different known charge level is required.
