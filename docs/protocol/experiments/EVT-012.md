# EVT-012 — charging cable connect/disconnect

Date: 2026-09-16
Transport: hidraw, opened read-only
Action: connect USB-C charging cable to powered wireless headset, wait, then
disconnect it

## Observed sequence

```text
connect:     08 5a
disconnect:  08 5a
```

The events occurred roughly 11 seconds apart and the payload was unchanged.

## Interpretation

- Strong hypothesis: Report `0x08` carries battery percentage. Payload `0x5a`
  is decimal 90, consistent with a plausible 90% battery level.
- Connecting or disconnecting external power causes the headset to resend this
  value.
- The one-byte report does not visibly distinguish charging from not charging
  in this experiment; both transitions emitted the same payload.
- Confirmation requires observing Report `0x08` at a different independently
  known battery level.
