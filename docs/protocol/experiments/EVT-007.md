# EVT-007 — dedicated microphone mute button

Date: 2026-09-16
Transport: hidraw, opened read-only
Initial condition: microphone boom lowered and microphone active
Action: dedicated mute button pressed, then pressed again after five seconds

## Observed sequence

```text
06 01  microphone=active
06 00  microphone=muted
2f 00  phone-mute-usage=released

2f 02  phone-mute-usage=asserted
06 01  microphone=active
2f 00  phone-mute-usage=released
```

## Conclusions

- Confirmed: both the boom mechanism and dedicated button converge on vendor
  Report `0x06` as the persistent microphone state.
- Confirmed: `06 00` is muted and `06 01` is active regardless of which
  physical control caused the transition.
- Report `0x2f` is a momentary host-facing Phone Mute usage. It did not appear
  symmetrically on the first transition, so it must not be used as the source
  of truth for persistent mute state.
- The initial repeated `06 01` before `06 00` may be a pre-transition state
  notification; further captures may clarify it, but it does not change the
  persistent mapping.
