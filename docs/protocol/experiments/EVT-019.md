# EVT-019 — analog audio cable

Date: 2026-09-16
Transport observed: 2.4 GHz dongle hidraw, read-only
Initial condition: headset wireless, ANC enabled
Cable: other end already connected to PC; 3.5 mm plug inserted into headset,
then removed

## Observed sequence

```text
connect cable:     02 00  noise-control=off
disconnect cable:  02 01  noise-control=anc
```

There was no audible notification and no observed LED change.

## Interpretation

- No dedicated analog-jack Input Report was observed.
- Inserting the cable appears to force noise control off.
- Removing it appears to restore the prior ANC state.
- Report `0x07` remains unidentified.
- EVT-020, performed with noise control already off, produced no report. This
  confirms there is no dedicated passive jack event; EVT-019 captured only the
  ANC side effect.
