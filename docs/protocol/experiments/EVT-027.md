# EVT-027 — Logo animation speed

Date: 2026-09-16
Transport observed: Windows 11 VM, USBPcap, dongle `0ecb:2069`
Initial condition: Logo animation speed 0.5x; Ring unchanged at 0.5x
Action: apply 1.0x, 1.5x, 2.0x, then restore 0.5x

## Observed

The zone header changed as follows:

```text
1.0x: 4c 00 4b 05
1.5x: 4c 00 32 05
2.0x: 4c 00 19 05
0.5x: 4c 00 64 05
```

The Ring header remained `4c 01 64 05` in every complete profile, providing a
negative control for the independently selected zone.

## Conclusion

The third byte in Feature Report `0x4c` is an inverse animation-speed value:
100, 75, 50, and 25 for 0.5x through 2.0x. The final byte remained `05` and
matches the five segments displayed by QuantumENGINE, but segment count remains
a strong hypothesis until independently varied.
