# EVT-035 — spatial audio disabled and enabled

Date: 2026-09-16
Transport observed: Windows 11 VM, USBPcap, dongle `0ecb:2069`
Initial condition: spatial audio enabled; DTS Headphone:X v2.0 selected
Action: disable spatial audio, wait, then enable it

## Result

Neither transition produced a USB transfer to the JBL device. There was no HID
Feature Report, HID interrupt notification, or USB Audio class-control request.
Only the ongoing audio stream and initial descriptor enumeration were present.

## Conclusion

The spatial-audio enable switch controls host-side processing in
QuantumENGINE/Windows. A Linux replacement belongs in a PipeWire spatializer
or equivalent DSP layer and requires no JBL vendor USB command.
