# EVT-021 — QuantumENGINE service startup

Date: 2026-09-16
Transport observed: Windows 11 VM, USBPcap, dongle `0ecb:2069`
Initial condition: QuantumENGINE application and service stopped
Action: start USB capture, then start the QuantumENGINE service

## Result

The capture contains HID interrupt traffic on endpoint `0x83` and 25 HID class
Feature Report requests on interface 5. QuantumENGINE read Reports `0x68`,
`0x67`, `0x62`, `0x5c`, `0x75`, `0x49`, `0x51`, `0x47`, `0x4a`, and `0x45`.
It also wrote Reports `0x4b`, `0x4c`, and `0x4d` during initialization.

Feature Report `0x49` returned payload `0x5a` (90 decimal), matching the
spontaneous `08 5a` Input Report previously observed on Linux.

## Safety conclusion

QuantumENGINE performs writes during normal startup. The complete startup
sequence must not be replayed on Linux until each write is independently
understood. The project remains read-only.
