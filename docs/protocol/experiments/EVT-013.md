# EVT-013 — startup while charging cable connected

Date: 2026-09-16
Transport: hidraw, opened read-only
Action: switch headset off and on while USB-C cable remains connected

## Observed sequence

```text
09 00
09 01
02 01
06 00
10 00
07 00
03 00
08 5a
08 5a  (approximately 1.7 seconds later)
```

## Comparison

The startup state values are identical to the earlier battery-powered startup
snapshot. Reports `0x02`, `0x03`, and `0x07` did not change. The only observed
difference was one additional repetition of `08 5a` after startup.

## Conclusions

- No simple charging flag is exposed by the observed passive startup reports.
- External power triggers additional Report `0x08` updates, reinforcing the
  battery/status interpretation.
- Charging state may be available only through a Feature Report, a vendor
  command, or another condition not represented in spontaneous Input Reports.
- No active Feature Report query was attempted.
