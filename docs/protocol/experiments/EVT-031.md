# EVT-031 — microphone gain

Date: 2026-09-16
Transport observed: Windows 11 VM, USBPcap, dongle `0ecb:2069`
Initial condition: microphone gain 100%
Action: set gain to 50%, wait, then restore 100%

## Result

Neither transition produced a USB transfer to the JBL device. In particular,
there was no HID Feature Report and no USB Audio class-control request. The
capture contains only the ongoing audio stream and USBPcap's initial descriptor
enumeration.

## Conclusion

The QuantumENGINE gain slider is a host-side capture-volume control rather than
a hardware gain setting. A Linux implementation should integrate with the
PipeWire/ALSA source volume and does not need a JBL vendor protocol write.
